# Revising a manuscript against comments

Accept three inputs in the conversation: the **paper folder**, **current version**, and **comments**. Comments can be pasted, attached as a reviewer letter, or embedded in a Word document or annotated PDF. Once the inputs identify the manuscript, begin editing.

1. **Identify the active manuscript.** Follow the named main file and its included sections. If the current version is a PDF, match it to the editable source in the folder. Ask which source to use only if the match is ambiguous. Use relevant figures, tables, bibliography and supplied results to check claims. Keep older versions out of the edits.
2. **Work on a separate copy.** Keep the original project intact. Give each distinct comment an ID and preserve its wording, location and marked text when available.
3. **Read the entire paper.** For each comment, locate the affected passage and dependent passages elsewhere. A changed definition may also affect the abstract, figure captions and conclusions. Apply local edits using the author's preferences. In a tune, keep wording that already works. In a rewrite, recast paragraphs as needed for clarity and flow.
4. **Return major decisions to the author.** A reviewer request is a proposal. Before changing scientific claims, moving material across sections, deleting substantive content or restructuring the paper, show the proposed change and why it helps. Apply only the major changes the user specifically approves. Record missing experiments, data or citations as questions for the author.
5. **Verify the deliverables.** Compare the original and revised text, run the applicable skill checks, and build the revised PDF when an editable LaTeX project and its dependencies are available. For Word, preserve equations, fields, citations, comments and formatting. Report any build failure or content you could not check.
6. **Return the revised manuscript and a comment report.** For every ID, record *addressed*, *partly addressed*, *already present*, or *needs author*. Give the revised file and passage supporting each resolution. Identify outstanding proposals and any evidence needed. Include the text diff and fresh PDF when available. Keep the response report local unless the user asks to send it.
